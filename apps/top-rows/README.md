# Top rows

The smallest useful app: a dropdown of every dataset the app may read, and the first ten rows of the one you pick, as a table.

Use it to check what a connector actually delivers before you build something bigger, or as the starting point for your own app: the whole file is 50 lines.

## Data it reads

Any dataset you tick when you run it. No specific connector required.

## Run it

Copy `index.html`, open https://autario.com/developer/build, choose **Paste HTML**, paste, tick one or more datasets, click **Run it**.
